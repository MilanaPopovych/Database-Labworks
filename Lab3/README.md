## Тема: Маніпулювання даними SQL (OLTP)
---
## Цілі
- Написати запити `SELECT` для отримання даних (включаючи фільтрацію за допомогою `WHERE` та вибір певних стовпців).
- Практикувати використання операторів `INSERT` для додавання нових рядків до таблиць.
- Практикувати використання оператора `UPDATE` для зміни існуючих рядків (використовуючи `SET` та `WHERE`).
- Практикувати використання операторів `DELETE` для безпечного видалення рядків (за допомогою `WHERE`).
- Вивчити основні операції маніпулювання даними (DML) у PostgreSQL та спостерігати за їхнім впливом.
---
## Результати

1. SELECT
```sql
-- SELECT: вивести імена, прізвища та пошту всіх викладачів ФІОТу, які зараз викладають
select first_name, second_name, email
from teacher
where faculty_id = 1 and status = 'викладає';
```

 insert into faculty (faculty_name, building)

## Висновки
Згідно з критеріями оцінювання, синтаксис SQL є коректним, а запити виконуються без помилок та дають правильні результати за рахунок правильного використання
`WHERE`, транзакцій і перевірки результатів. Було вивчено основні операції маніпулювання даними (DML) в PostgreSQL, в тому числі операції упорядковування, 
види CRUD-операцій та способи їхнього застосування при роботі з елементами баз даних.
